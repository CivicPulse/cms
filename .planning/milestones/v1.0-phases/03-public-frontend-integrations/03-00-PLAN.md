     - This file provides helper functions for seeding test data via Payload's Local API.
     - Import `getPayload` from 'payload' and `configPromise` from a relative path to `../src/payload.config.ts` (adjust if needed for Playwright's test runner context).

     - Export `getTestPayload()`:
       ```typescript
       export async function getTestPayload() {
         const payload = await getPayload({ config: configPromise })
         return payload
       }
       ```
     - Export `seedTestTenant(payload, slug?: string)`:
       - Creates a tenant with slug (default: 'test-campaign'), displayName 'Test Campaign', status 'active'
       - Uses `overrideAccess: true`
       - Returns the created tenant doc
     - Export `seedSiteSettings(payload, tenantId)`:

     - Export `seedPost(payload, tenantId, overrides?: Partial)`:
       - Creates a published post with title 'Test Post', slug 'test-post', content (minimal Lexical state with a paragraph), publishAs 'web', _status 'published'
       - Merges overrides
       - Returns the created doc
     - Export `cleanupTestData(payload, tenantId)`:
       - Deletes posts, pages, site-settings for the tenant, then the tenant itself
       - All with `overrideAccess: true`
       - Wraps in try/catch to avoid test failures on cleanup
