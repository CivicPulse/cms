<objective>
Build the three template component trees (Classic, Modern, Bold) with their distinct visual identities, and wire the template registry so layouts can be selected via activeTemplateKey.

Purpose: Templates are the core visual differentiator of the platform. Each template provides a complete layout (Nav + Hero + content area + Footer) with distinct typography, color palette, and hero treatment. Campaigns switch templates via SiteSettings without touching content.

Output: 9 template component files (3 per template: Layout, Nav, Hero) plus updated template registry in lib/templates.ts.

Note: This plan creates 10 files across 2 tasks (at the warning threshold). The split is clean -- Task 1 creates Classic + Modern (6 files), Task 2 creates Bold + wires the registry (4 files). Each template is a cohesive unit.
</objective>
