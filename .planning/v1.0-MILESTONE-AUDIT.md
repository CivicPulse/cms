## Integration Issues

### INT-01: Missing Phase 3 Migration (Critical)

Phase 3 Plan 01 added `versions/drafts`, `featuredImage`, and `navItems` to the Postgres schema. No migration file was committed. Development works via `push: process.env.NODE_ENV === 'development'` but production (where `push: false`) cannot apply these schema changes.

**Fix:** Run `npx payload migrate:create` to generate the migration, commit the file to `src/migrations/`, and run `npx payload migrate` before production deployment.

**Affected:** FOUND-02 (migration workflow), CONF-02 (navItems), FRONT-02 (homepage rendering), FRONT-04 (featuredImage on posts)

### INT-02: Stale Generated Types (Moderate)

`src/payload-types.ts` lacks `featuredImage` on `Post` and `navItems` on `SiteSetting`. Components use `as unknown as Record<string, unknown>` type assertions. Self-resolves after `npx payload generate:types`.

### INT-03: Orphaned API Helpers (Minor)

`src/lib/api.ts` exports `subscribeToNewsletter` and `updateSubscriber` but no component imports them. The newsletter flow works via duplicate inline `fetch()` calls. URL changes would need to be made in 3 places.
