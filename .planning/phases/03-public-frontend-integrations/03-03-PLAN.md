  <action>
  Create 6 shared component files. All use Tailwind CSS classes. Components that need interactivity use 'use client'.

  1. **src/components/shared/InitialsAvatar.tsx** (Server Component):
     - Props: `{ name: string, size?: 'sm' | 'md' | 'lg', className?: string }`
     - Extract initials from name: split on spaces, take first letter of first and last word, uppercase
     - Render a circle div with primaryColor background (use `bg-primary text-white`) and centered initials text
     - Size mapping: sm = 40px/text-sm, md = 64px/text-lg, lg = 96px/text-2xl
     - Use `rounded-full flex items-center justify-center font-bold` base classes

  2. **src/components/shared/PostCard.tsx** (Server Component):
     - Props: `{ post: { title, slug, featuredImage?, createdAt, content? }, basePath?: string }`
     - Renders a card linking to `{basePath ?? '/blog'}/{post.slug}`
     - If featuredImage exists and has url: render image with `next/image` or `<img>` with src from media URL. Use aspect-ratio-video, object-cover.
     - If no featuredImage: render a placeholder div with `bg-gray-100` and a subtle newspaper icon or gradient
     - Title as h3, truncate to 2 lines via `line-clamp-2`
     - Date formatted as "Month Day, Year" using `new Date(post.createdAt).toLocaleDateString('en-US', { month: 'long', day: 'numeric', year: 'numeric' })`
     - Excerpt: extract first ~150 chars from content if it's rich text (grab first text node), or show empty. Use `line-clamp-3 text-sm text-gray-600`
     - Card has `rounded-lg overflow-hidden shadow-sm hover:shadow-md transition-shadow` styling

  3. **src/components/shared/Pagination.tsx** (Server Component):
     - Props: `{ currentPage: number, totalPages: number, basePath: string }`
     - Renders prev/next navigation: "Newer Posts | Page X of Y | Older Posts"
     - "Newer Posts" links to `{basePath}?page={currentPage - 1}`, hidden when currentPage === 1
     - "Older Posts" links to `{basePath}?page={currentPage + 1}`, hidden when currentPage === totalPages
     - Use `flex justify-between items-center py-8` layout
     - Links styled with `text-primary hover:underline font-medium`

  4. **src/components/shared/ShareButtons.tsx** ('use client'):
     - Props: `{ url: string, title: string }`
     - Four buttons/links:
       a. Facebook: `https://www.facebook.com/sharer/sharer.php?u=${encoded}` -- target="_blank"
       b. X/Twitter: `https://twitter.com/intent/tweet?url=${encoded}&text=${encodedTitle}` -- target="_blank"
       c. Email: `mailto:?subject=${encodedTitle}&body=${encoded}`
       d. Copy Link: button with onClick `navigator.clipboard.writeText(url)`, shows "Copied!" feedback for 2 seconds via useState
     - Layout: `flex gap-3 items-center` with icon-like styled links
     - Each link/button has `text-sm text-gray-500 hover:text-primary transition-colors` styling

  5. **src/components/shared/NewsletterForm.tsx** ('use client'):
     - Props: `{ campaignId: string, runApiUrl: string, compact?: boolean, className?: string }`
     - State: email (string), status ('idle' | 'loading' | 'success' | 'error')
     - On submit: POST to `${runApiUrl}/api/v1/campaigns/${campaignId}/subscribers` with `{ email }`
     - If res.ok: set status to 'success'
     - If error: set status to 'error'
     - Compact mode (for footer): single row with inline input + button
     - Full mode (for /newsletter page): stacked layout with more description
     - Input: `type="email" required placeholder="Your email address"` with Tailwind form styling
     - Button: `bg-primary text-white px-4 py-2 rounded-md hover:bg-primary-hover transition-colors disabled:opacity-50`
     - Success: green text "You're subscribed! Check your inbox."
     - Error: red text "Something went wrong. Please try again."
     - On success, show a "Want to add your name?" link that navigates to /newsletter/thank-you

  6. **src/components/shared/MobileNav.tsx** ('use client'):
     - Props: `{ navItems: Array<{ label: string, url: string }>, candidateName: string }`
     - Hamburger button (3 horizontal lines icon via div elements or inline SVG) visible on mobile (md:hidden)
     - On click: toggles a full-screen overlay with nav items listed vertically
     - External links (url starts with 'http') get target="_blank" and rel="noopener noreferrer"
     - Close button (X icon) in top-right of overlay
     - Overlay has dark semi-transparent background with white nav panel sliding in from right
     - Body scroll locked when open (via overflow-hidden on body)

  <action>
  Create 7 component files. Block renderers convert Payload block data to visual components. StickyActionBar and Footer are shared layout components.

  1. **src/components/blocks/BlockRenderer.tsx** (Server Component):
     - Props: `{ blocks: Array<{ blockType: string, [key: string]: unknown }>, siteSettings?: SiteSettings }`
     - Maps over blocks array, switches on `blockType`:
       - 'hero' -> HeroBlockRenderer
       - 'text' -> TextBlockRenderer
       - 'issues' -> IssuesBlockRenderer
       - 'contact' -> ContactBlockRenderer (passes siteSettings for fallback contactEmail and newsletter form)
       - unknown -> null (skip gracefully)
     - Each block wrapped in a `<section key={block.id}>` for proper React keying

  2. **src/components/blocks/HeroBlockRenderer.tsx** (Server Component):
     - Props: block data matching HeroBlock fields (headline, subheadline, backgroundImage, ctaLabel, ctaUrl)
     - If backgroundImage exists: render as background with dark overlay for text readability
     - Headline as h2, subheadline as p
     - CTA button if both ctaLabel and ctaUrl provided: link styled as `bg-primary text-white px-6 py-3 rounded-md`
     - Section padding: `py-16 px-4`
     - Without background: use `bg-gray-50` as fallback

  3. **src/components/blocks/TextBlockRenderer.tsx** (Server Component):
     - Props: block data with content (Lexical rich text)
     - Import `RichText` from `@payloadcms/richtext-lexical/react`
     - Render: `<div className="prose prose-lg max-w-none"><RichText data={content} /></div>`
     - Section padding: `py-12 px-4`
     - The prose class from Tailwind provides sensible typography defaults for rich text

  4. **src/components/blocks/IssuesBlockRenderer.tsx** (Server Component):
     - Props: block data with items array (each has title, description)
     - Render issues as a grid of cards: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`
     - Each card: white bg, rounded, padded, with title as h3 and description as p (plain text)
     - Left border accent with primaryColor: `border-l-4 border-primary`
     - Section heading: "Key Issues" or use a section title if provided

  5. **src/components/blocks/ContactBlockRenderer.tsx** (Server Component + passes client props):
     - Props: block data (contactEmail, officeAddress, phoneNumber, showNewsletterForm) + siteSettings
     - Contact info section with email (mailto link), address, phone
     - If contactEmail is empty, fall back to siteSettings.contactEmail
     - If showNewsletterForm is true: render NewsletterForm component with campaignId from tenant
     - Layout: centered content, `max-w-2xl mx-auto`

  6. **src/components/shared/StickyActionBar.tsx** (Server Component):
     - Props: `{ navItems: Array<{ label: string, url: string }>, donationUrl?: string }`
     - Filter navItems to only external links (url starts with 'http')
     - If donationUrl exists and isn't already in navItems, prepend a "Donate" button
     - If no external items after filtering: return null (bar hidden)
     - Render a fixed bar below the nav: `sticky top-0 z-40 bg-primary text-white py-2 px-4`
     - Buttons: `flex gap-3 justify-center` with each item as an anchor styled as a pill button
     - All external links open in new tab with rel="noopener noreferrer"
     - NOTE: the sticky bar sits BELOW the nav. Use `z-40` so it's above page content but below mobile nav overlay (z-50).

  7. **src/components/shared/Footer.tsx** (Server Component):
     - Props: `{ siteSettings: SiteSettings, campaignId: string, runApiUrl: string }`
     - Three-row layout:
       a. Top row: Newsletter form (compact mode) with heading "Stay Updated"
       b. Middle row: Campaign name + social icons (twitterUrl, facebookUrl, instagramUrl -- only show icons for configured URLs) + contact email
       c. Bottom row: "Paid for by {candidateName} for {officeRunningFor}" disclaimer + "Powered by CivPulse" small link
     - Social icons: use simple SVG icons inline (no icon library) for Twitter/X, Facebook, Instagram
     - Layout: `bg-gray-900 text-white py-12 px-4` with `max-w-6xl mx-auto`
     - NewsletterForm gets compact=true prop
     - Pass `runApiUrl` and `campaignId` to NewsletterForm
  </action>
