     - Fetch: getPageBySlug(tenant.id, 'home') -> get the homepage's editable blocks
     - Fetch: getPublishedPosts(tenant.id, { limit: 9 }) -> recent posts for grid
     - Get template: `const Template = getTemplate(siteSettings.activeTemplateKey)`
     - Get hero: import all 3 heroes, select based on activeTemplateKey:
       ```typescript
       const heroComponents = { classic: ClassicHero, modern: ModernHero, bold: BoldHero }
       const Hero = heroComponents[siteSettings.activeTemplateKey as TemplateKey] ?? ModernHero
       ```
     - Render structure (fixed sandwich per CONTEXT.md decisions):
       ```tsx
       <Template siteSettings={siteSettings} campaignId={tenantId} runApiUrl={runApiUrl}>
         {/* 1. Hero from SiteSettings */}
         <Hero siteSettings={siteSettings} />

         {/* 2. Meet the Candidate (only if bio is filled) */}
         {siteSettings.bio && (
           <section className="py-16 px-4">
             <div className="max-w-5xl mx-auto flex flex-col md:flex-row gap-8 items-center">
               {/* Photo or InitialsAvatar */}
               <div className="md:w-1/3">
                 {candidatePhoto ? <img ... /> : <InitialsAvatar name={siteSettings.candidateName} size="lg" />}
               </div>
               <div className="md:w-2/3">
                 <h2 className="text-2xl font-bold mb-4">Meet {siteSettings.candidateName}</h2>
                 <p className="text-lg leading-relaxed">{siteSettings.bio}</p>
               </div>
             </div>
           </section>
         )}

         {/* 3. Editable blocks from Pages "home" */}
         {homePage?.layout && <BlockRenderer blocks={homePage.layout} siteSettings={siteSettings} />}

         {/* 4. Recent posts grid */}
         {posts.docs.length > 0 && (
           <section className="py-16 px-4">
             <div className="max-w-6xl mx-auto">
               <h2 className="text-2xl font-bold mb-8">Latest Updates</h2>
               <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
                 {posts.docs.map(post => <PostCard key={post.id} post={post} />)}
               </div>
               {posts.totalPages > 1 && (
                 <div className="mt-8 text-center">
                   <a href="/blog" className="text-primary hover:underline font-medium">
                     View all posts &rarr;
                   </a>
                 </div>
               )}
             </div>
           </section>
         )}
       </Template>
       ```
     - Export `generateMetadata`: return title as `{candidateName} | {officeRunningFor}`, description as tagline, open graph image from candidatePhoto
     - Get `runApiUrl` from `process.env.RUN_API_BASE_URL ?? ''` and `campaignId` from `tenant.id.toString()`

  2. **src/app/(frontend)/blog/[slug]/page.tsx** (Individual post):
     - Async Server Component
     - Params: `{ slug }` from URL (await params in Next.js 15)
     - Fetch: getTenantBySlug(), getSiteSettings(), getPostBySlug(tenant.id, slug)
     - If no post found: call notFound()
     - Get template Layout
     - Import RichText from '@payloadcms/richtext-lexical/react'
     - Render:
       ```tsx
       <Template ...>
         <article className="py-12 px-4">
           <div className="max-w-3xl mx-auto">
             <h1 className="text-3xl lg:text-4xl font-bold mb-4">{post.title}</h1>
             <div className="text-sm text-gray-500 mb-8">
               {new Date(post.createdAt).toLocaleDateString('en-US', {
                 month: 'long', day: 'numeric', year: 'numeric'
               })}
             </div>
             {post.featuredImage?.url && (
               <div className="mb-8 rounded-lg overflow-hidden">
                 <img src={post.featuredImage.url} alt={post.featuredImage.alt ?? post.title} className="w-full h-auto object-cover" />
               </div>
             )}
             {post.content && (
               <div className="prose prose-lg max-w-none">
                 <RichText data={post.content} />
               </div>
             )}
             <div className="mt-12 pt-8 border-t">
               <p className="text-sm text-gray-500 mb-3">Share this post</p>
               <ShareButtons url={`${process.env.SITE_DOMAIN ? `https://${tenantSlug}.${process.env.SITE_DOMAIN}` : ''}/blog/${post.slug}`} title={post.title} />
             </div>
           </div>
         </article>
       </Template>
       ```
