<task type="auto">
  <name>Task 2: Middleware + lib utilities (tenant, templates, api)</name>
  <files>src/middleware.ts, src/lib/tenant.ts, src/lib/templates.ts, src/lib/api.ts</files>
  <action>
  1. **Create src/middleware.ts:**
     - Import NextRequest, NextResponse from 'next/server'
     - Export `middleware` function:
       a. Extract hostname from `request.headers.get('host') ?? ''`
       b. Implement `extractSubdomain(hostname)`:
          - For localhost: split on '.', if parts.length > 1, first part is subdomain (handles `jones.localhost:3000`)
          - For production: read SITE_DOMAIN from `process.env.SITE_DOMAIN`. If hostname ends with SITE_DOMAIN, extract the subdomain prefix. Otherwise return null.
       c. If no subdomain: return `NextResponse.next()` (root domain passthrough)
       d. If subdomain found: clone request headers, set `x-tenant-slug` header to the subdomain, return `NextResponse.next({ request: { headers: requestHeaders } })`
     - Export `config` with matcher that EXCLUDES Payload admin, API, Next.js internals, and static files:
       ```typescript
       export const config = {
         matcher: ['/((?!admin|api|_next/static|_next/image|favicon.ico).*)'],
       }
       ```
     - NOTE: Do NOT import env.ts in middleware -- middleware runs in Edge Runtime where Zod parse may not be available. Use `process.env.SITE_DOMAIN` directly with a fallback for localhost dev.

  2. **Create src/lib/tenant.ts:**
     - Import `headers` from 'next/headers' (async in Next.js 15)
     - Import `getPayload` from 'payload' and `configPromise` from '@payload-config'
     - Export `getTenantBySlug()`:
       a. `const headersList = await headers()`
       b. `const slug = headersList.get('x-tenant-slug')`
       c. If no slug, return null
       d. Query tenants collection: `payload.find({ collection: 'tenants', where: { slug: { equals: slug } }, limit: 1, overrideAccess: true })`
       e. Return `result.docs[0] ?? null`
     - Export `getSiteSettings(tenantId: string | number)`:
       a. Query site-settings: `payload.find({ collection: 'site-settings', where: { tenant: { equals: tenantId } }, limit: 1, depth: 2, overrideAccess: true })`
       b. `depth: 2` is critical -- populates media relations (logo, candidatePhoto) so URLs are available
       c. Return `result.docs[0] ?? null`
     - Export `getPublishedPosts(tenantId: string | number, options?: { page?: number, limit?: number })`:
       a. Query posts: `payload.find({ collection: 'posts', where: { tenant: { equals: tenantId }, _status: { equals: 'published' }, publishAs: { in: ['web', 'both'] } }, sort: '-createdAt', page: options?.page ?? 1, limit: options?.limit ?? 9, depth: 2, overrideAccess: true })`
       b. Return the full paginated result (totalDocs, totalPages, hasNextPage, hasPrevPage, docs, page)
     - Export `getPostBySlug(tenantId: string | number, slug: string)`:
       a. Query posts with slug match + published + web/both filter, limit 1, depth 2
       b. Return `result.docs[0] ?? null`
     - Export `getPageBySlug(tenantId: string | number, slug: string)`:
       a. Query pages with slug match, limit 1, depth 2 (for media in blocks)
       b. Return `result.docs[0] ?? null`
     - Use `overrideAccess: true` on ALL queries -- public frontend has no user session. Tenant scoping is done explicitly via `where` clauses.

  3. **Create src/lib/templates.ts:**
     - Create a placeholder template registry. The actual template components will be created in Plan 03.
     - Export type `TemplateKey = 'classic' | 'modern' | 'bold'`
     - Export `getTemplateKey(key: string): TemplateKey` -- validates key, falls back to 'modern' for unknown values
     - Export placeholder for future template component mapping (comment indicating Plan 03 will populate)

  4. **Create src/lib/api.ts:**
     - Export `subscribeToNewsletter(params: { email: string, campaignId: string })`:
       a. `const baseUrl = process.env.RUN_API_BASE_URL ?? process.env.NEXT_PUBLIC_RUN_API_BASE_URL`
       b. POST to `${baseUrl}/api/v1/campaigns/${campaignId}/subscribers` with `{ email }` body
       c. Return `{ ok: boolean, error?: string }`
       d. Mark as 'use server' if needed (or keep as a plain async function for client component usage via a server action wrapper)
     - Export `updateSubscriber(params: { campaignId: string, email: string, name?: string, zipCode?: string })`:
       a. PATCH to subscriber endpoint with optional name and zip
       b. Return `{ ok: boolean, error?: string }`
